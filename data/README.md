# Data

Datasets are **not committed** to this repository — either because of their
license (FinancialPhraseBank is non-commercial) or because they are proprietary
(the stock data comes from a paid database). Obtain them yourself and place them
here as described below.

---

## 1. FinancialPhraseBank (financial sentiment)

- **What**: ~4 840 English financial news sentences labelled
  positive / neutral / negative. Used by notebooks `01`, `02`, `04`, `05`.
- **Source**: Malo et al. (2014). Available on
  [Kaggle](https://www.kaggle.com/datasets/ankurzing/sentiment-analysis-for-financial-news)
  and [Hugging Face Datasets](https://huggingface.co/datasets/financial_phrasebank).
- **License**: **Creative Commons BY-NC-SA 3.0** (Attribution,
  **Non-Commercial**, Share-Alike). This is why the data is not redistributed here.
- **Expected layout**:

  ```
  data/FinancialPhraseBank/
  ├── Sentences_AllAgree.txt      # 100% annotator agreement
  └── Sentences_75Agree.txt       # >75% agreement   (both used by the notebooks)
  ```

- **Derived files**: `eng_sent.txt`, `chn_sent.txt`, `labels.json` are
  **generated by the notebooks** (`04` writes the English sentences + labels,
  `05` writes the machine-translated Chinese). You do not need to download them.

> Citation: P. Malo, A. Sinha, P. Korhonen, J. Wallenius, and P. Takala,
> "Good debt or bad debt: Detecting semantic orientations in economic texts,"
> *Journal of the Association for Information Science and Technology*, 2014.

## 2. Stock data (Kweichow Moutai et al.)

- **What**: 2021 daily A-share data used by `03_stock_price_gru_tcn.ipynb`
  to forecast Kweichow Moutai (ticker 600519 / 600809 in the sheet).
- **Source**: **RESSET financial database** — a commercial, subscription-only
  data vendor.
- **License**: **Proprietary.** Redistribution is not permitted, so the original
  file is **not included**. If you have RESSET access, export the daily table and
  save it as:

  ```
  data/Stock/RESSET_DRESSTK_2021__1.xlsx     # sheet name: DRESSTK_2021_
  ```

  Without this file, notebook `03` cannot be run; the other four notebooks are
  unaffected.
